Loop for (int step = 0; step < steps; step++):
Subtract stepDt from currentGeneration.ActiveTimeLeft.
If currentGeneration.ActiveTimeLeft <= 0, call PrepareEndGeneration(); and break; out of the loop (so the window still renders and stays responsive between generations).

Read the target's live physics position directly from TargetCube.Rbody.Position (important: TargetCube.GetPosition() only refreshes when PhysicsObject.Update runs at the end of the frame, whereas Rbody.Position is always up to date inside the substep loop).
